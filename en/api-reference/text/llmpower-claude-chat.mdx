## Authentication

Use the `Authorization` header for authentication.

```bash
Authorization: Bearer {{YOUR_API_KEY}}
Content-Type: application/json
```

Notes:

- `Authorization`: API key in the format `Bearer {{YOUR_API_KEY}}`

## Supported Models

The following models are supported, organized by model family and version type:

### Claude

| Full Version | AWS Version | Account Pool / Proxy Version |
| --- | --- | --- |
| `claude-haiku-4-5` | `claude-haiku-4-5-hc` | `claude-haiku-4-5-fd` |
| `claude-opus-4-5` | `claude-opus-4-5-hc` | `claude-opus-4-5-fd` |
| `claude-opus-4-6` | `claude-opus-4-6-hc` | `claude-opus-4-6-fd` |
| `claude-opus-4-7` | `claude-opus-4-7-hc` | `claude-opus-4-7-fd` |
| `claude-sonnet-4-5` | `claude-sonnet-4-5-hc` | `claude-sonnet-4-5-fd` |
| `claude-sonnet-4-6` | `claude-sonnet-4-6-hc` | `claude-sonnet-4-6-fd` |

### GPT Models Compatible with Claude Messages API

| Full Version | Official Version | Premium Account Pool | Mixed Account Pool / Proxy Version | Low-cost Version |
| --- | --- | --- | --- | --- |
| `gpt-5.4` | `gpt-5.4-official` | `gpt-5.4-hc` | `gpt-5.4-fd` | `gpt-5.4-low` |
| `gpt-5.5` | `gpt-5.5-official` | `gpt-5.5-hc` | `gpt-5.5-fd` | `gpt-5.5-low` |

### Version Notes

| Suffix / Type | Description |
| --- | --- |
| no suffix | Full version / official standard version |
| `-official` | Official version |
| `-hc` | AWS version or premium account pool version |
| `-fd` | Account pool / proxy version |
| `-low` | Low-cost version |

<Note>
Claude Messages API uses the Claude request schema and is not suitable for the official Gemini native format. For Gemini native requests, use the Gemini Native API. GPT models can be called through this format, but image recognition is currently not supported for them.
</Note>

## Request Parameters

<ParamField path="model" type="string" required>
  Model name to use, for example: `claude-opus-4-7` or `gpt-5.5`
</ParamField>

<ParamField path="max_tokens" type="integer" required>
  Maximum number of tokens allowed for this request
</ParamField>

<ParamField path="messages" type="array" required>
  Message array in Claude Messages format
</ParamField>

<ParamField path="messages[].role" type="string" required>
  Message role, commonly `user` or `assistant`
</ParamField>

<ParamField path="messages[].content" type="string/array" required>
  Message content. Can be a string or a Claude native content block array
</ParamField>

<ParamField path="system" type="string">
  Optional system prompt
</ParamField>

<ParamField path="stream" type="boolean">
  Whether to enable streaming responses. When enabled, Claude-style streaming events are returned
</ParamField>

<ParamField path="temperature" type="number">
  Sampling temperature
</ParamField>

## Response

Returns a Claude Messages-style response.

<ResponseField name="id" type="string">
  Unique response identifier
</ResponseField>

<ResponseField name="type" type="string">
  Response type, usually `message`
</ResponseField>

<ResponseField name="role" type="string">
  Returned message role, usually `assistant`
</ResponseField>

<ResponseField name="content[].type" type="string">
  Content block type, commonly `text`
</ResponseField>

<ResponseField name="content[].text" type="string">
  Generated text content
</ResponseField>

<ResponseField name="stop_reason" type="string">
  Generation stop reason
</ResponseField>

<ResponseField name="usage.input_tokens" type="integer">
  Input token count
</ResponseField>

<ResponseField name="usage.output_tokens" type="integer">
  Output token count
</ResponseField>

## Notes

<Note>
1. The Claude-format request path is `POST /v1/messages`
2. For streaming responses, pass `"stream": true` in the request body
3. Pass the API key using the `Authorization` header
</Note>
