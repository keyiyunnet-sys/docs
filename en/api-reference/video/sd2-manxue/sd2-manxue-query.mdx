# Sd2 Manxue Query Video Task

Use the task ID to query the status and result of an `sd2_manxue` video generation task.

## Authentication

All requests require a Bearer token in the request header:

```bash
Authorization: Bearer {{key}}
```

<ApiBaseUrlEn />

## Path parameters

<ParamField path="id" type="string" required>
  Unique identifier of the video generation task, returned by the create task API.

  <Note>The create API returns the field `id` directly. Use that value as the `id` here.</Note>
</ParamField>

## Response parameters

<ResponseField name="id" type="string">
  Unique identifier of the video generation task.
</ResponseField>

<ResponseField name="object" type="string">
  Object type, always `video`.
</ResponseField>

<ResponseField name="created" type="integer">
  Task creation timestamp.
</ResponseField>

<ResponseField name="model" type="string">
  Model name used for generation, such as `sd2_manxue_1080p`.
</ResponseField>

<ResponseField name="status" type="string">
  Task status:
  - `queued` - Queued
  - `processing` - Processing
  - `completed` - Completed
  - `failed` - Failed
</ResponseField>

<ResponseField name="video_url" type="string">
  Generated video URL, returned when the task is `completed`.
</ResponseField>

<ResponseField name="actualDuration" type="number">
  Actual output duration in seconds, returned when the task is `completed`.
</ResponseField>

<ResponseField name="error" type="string">
  Error message, returned when the task is `failed`.
</ResponseField>

## Status flow

<Steps>
  <Step title="queued">
    The task has been created and added to the queue.
  </Step>
  <Step title="processing">
    The `sd2_manxue` model is actively generating the video.
  </Step>
  <Step title="completed">
    The task has completed successfully and the result is available through `video_url`.
  </Step>
</Steps>

## Polling recommendations

<Info>
**Polling strategy:**
- Recommended polling interval: 30-60 seconds
- Most tasks complete within a few minutes, but scenarios with multiple reference assets may take longer
- Avoid aggressive polling to reduce the risk of rate limiting
- Stop polling when the status becomes `completed` or `failed`
</Info>

## Result notes

<Warning>
**Important:**
- Generated result URLs are usually temporary, so save them promptly
- Tasks using multiple reference images, videos, or audios may take longer to complete
- Invalid prompts or unsupported reference materials may cause task failure
</Warning>
