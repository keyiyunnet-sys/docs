# Sd2 Manxue 创建视频任务

创建 `sd2_manxue` 视频生成任务。该接口支持纯文生、首帧图生、首尾帧，以及图片、视频、音频混合参考模式。

## 认证

所有请求都需要在请求头中包含 Bearer token：

```bash
Authorization: Bearer {{key}}
```

## 请求参数

<ParamField body="prompt" type="string" required>
  视频生成提示词。

  示例：`"一个女生在雨夜街头慢跑，霓虹灯倒影，镜头平滑推进，电影感强"`
</ParamField>

<ParamField body="model" type="string" required>
  模型名称，用于确定输出分辨率。

  可选值：
  - `sd2_manxue_720p` - 输出 `720p`
  - `sd2_manxue_1080p` - 输出 `1080p`
  - `sd2_manxue_2k` - 输出 `2k`
  - `sd2_manxue_4k` - 输出 `4k`
</ParamField>

<ParamField body="duration" type="integer">
  视频时长（秒），默认 `5`，支持范围 `4-15`。
</ParamField>

<ParamField body="ratio" type="string">
  输出比例，默认 `16:9`。

  支持的值：
  - `21:9`
  - `16:9`
  - `4:3`
  - `1:1`
  - `3:4`
  - `9:16`
</ParamField>

<ParamField body="image" type="string">
  首帧图片 URL。

  使用规则：
  - 可单独用于首帧模式
  - 搭配 `lastFrameImage` 时表示首尾帧模式
  - 不能与 `referenceImages`、`referenceVideos`、`referenceAudios` 同时使用

  图片建议宽高比在 `0.4 ~ 2.5` 之间，宽高建议在 `300 ~ 6000 px` 之间。
</ParamField>

<ParamField body="lastFrameImage" type="string">
  尾帧图片 URL。

  <Note>必须搭配 `image` 使用</Note>
</ParamField>

<ParamField body="referenceImages" type="array">
  参考图片 URL 列表。

  规则说明：
  - 最多 `9` 张
  - 不能与 `image`、`lastFrameImage` 同时使用
  - 图片建议宽高比在 `0.4 ~ 2.5` 之间，宽高建议在 `300 ~ 6000 px` 之间

  <Note>涉及人脸或虚拟人像素材时，建议先调用素材审核接口并使用 `asset://{assetId}` 形式引用</Note>
</ParamField>

<ParamField body="referenceVideos" type="array">
  参考视频 URL 列表。

  规则说明：
  - 最多 `3` 个
  - 总时长不超过 `15` 秒
  - 总大小不超过 `500MB`
  - 不能与 `image`、`lastFrameImage` 同时使用
</ParamField>

<ParamField body="referenceAudios" type="array">
  参考音频 URL 列表。

  规则说明：
  - 最多 `3` 个
  - 总时长不超过 `15` 秒
  - 总大小不超过 `500MB`
  - 不能与 `image`、`lastFrameImage` 同时使用
</ParamField>

## 响应参数

<ResponseField name="code" type="string">
  状态码，`0` 表示成功。
</ResponseField>

<ResponseField name="msg" type="string">
  返回信息。失败时通常返回错误原因。
</ResponseField>

<ResponseField name="data.projectId" type="string">
  系统任务 ID。

  请保存该值，用于后续查询生成结果。
</ResponseField>

## 参数选择规则

<Warning>
**互斥规则：**
- `lastFrameImage` 不能单独使用，必须与 `image` 成对出现
- `referenceImages`、`referenceVideos`、`referenceAudios` 可单独或组合使用
- `image` / `lastFrameImage` 与任意 `reference*` 参数不能同时使用
</Warning>

## 模型与分辨率

| 模型 | 输出分辨率 | 适用场景 |
|------|------------|----------|
| `sd2_manxue_720p` | `720p` | 更关注生成速度与基础效果 |
| `sd2_manxue_1080p` | `1080p` | 常规高清生成 |
| `sd2_manxue_2k` | `2k` | 更高精度的视频内容 |
| `sd2_manxue_4k` | `4k` | 对画质要求最高的场景 |

<Info>
**最佳实践：**
1. 创建任务为异步处理，请保存返回的 `projectId`。
2. 提示词尽量包含主体、动作、镜头和风格描述。
3. 使用首尾帧模式时，建议两张图片在风格和构图上连续。
4. 使用参考视频或参考音频时，优先提供时长较短、主体清晰的素材。
5. 涉及人脸或虚拟人像的参考素材，建议先完成素材审核。
</Info>
