# StarVideos O3 创建视频任务

使用 `starvideos_o3` 创建视频生成任务。该接口支持文生视频、单图/多图参考、首尾帧、视频参考、图片 + 视频、多图 + 视频等能力。

## 认证

所有请求都需要在请求头中包含 Bearer token：

```bash
Authorization: Bearer {{key}}
```

## 请求参数

<ParamField body="model" type="string" required>
  模型名称，固定为 `starvideos_o3`。
</ParamField>

<ParamField body="prompt" type="string" required>
  视频生成提示词，描述画面内容、动作、镜头和风格。

  示例：`"赛博朋克城市夜景，镜头慢慢推进"`
</ParamField>

<ParamField body="duration" type="integer">
  视频时长，单位为秒。适用于文生视频、图片参考和首尾帧模式。

  - 默认值：`3`
  - 支持范围：`3-15`
  - 视频参考、图片 + 视频、多图 + 视频场景下，生成时长以参考视频素材为准
</ParamField>

<ParamField body="ratio" type="string">
  输出画面比例。适用于文生视频、图片参考和首尾帧模式。

  - 默认值：`9:16`
  - 可选值：`1:1`、`9:16`、`16:9`
  - 视频参考、图片 + 视频、多图 + 视频场景下，画面比例以参考视频素材为准
</ParamField>

<ParamField body="referenceImages" type="array">
  图片参考 URL 数组，O3 图片输入主字段。

  使用规则：
  - 纯图片参考：最多 `7` 张
  - 搭配 `referenceVideos`：最多 `4` 张
  - 首尾帧模式不使用该字段，请使用 `first_image` + `last_image`

  示例：`["https://example.com/image1.jpg", "https://example.com/image2.jpg"]`
</ParamField>

<ParamField body="first_image" type="string">
  首帧图片 URL，仅首尾帧模式使用，必须搭配 `last_image`。
</ParamField>

<ParamField body="last_image" type="string">
  尾帧图片 URL，仅首尾帧模式使用，必须搭配 `first_image`。
</ParamField>

<ParamField body="referenceVideos" type="array">
  视频参考 URL 数组，最多 `1` 个视频，参考视频时长需在 `3-10` 秒内。

  搭配视频参考时，生成时长和画面比例以参考视频素材为准。

  示例：`["https://example.com/source.mp4"]`
</ParamField>

## 参数约束

<Warning>
**关键约束：**
- `model` 仅支持 `starvideos_o3`
- `duration` 支持 `3-15` 秒，默认 `3`
- `ratio` 支持 `1:1`、`9:16`、`16:9`，默认 `9:16`
- `referenceImages` 纯图片模式最多 `7` 张，搭配视频时最多 `4` 张
- `referenceVideos` 最多 `1` 个视频，参考视频时长需在 `3-10` 秒内
- `first_image` 与 `last_image` 必须成对传入
- `first_image` / `last_image` 不能与 `referenceImages`、`referenceVideos` 混用
</Warning>

<Info>
**字段说明：**
`starvideos_o3` 图片输入统一使用 `referenceImages`，首尾帧输入统一使用 `first_image` + `last_image`。
</Info>

## 响应参数

<ResponseField name="id" type="string">
  视频生成任务的唯一标识符，用于后续查询任务状态。
</ResponseField>

<ResponseField name="object" type="string">
  对象类型，固定为 `video`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建时间戳。
</ResponseField>

<ResponseField name="model" type="string">
  使用的模型名称。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：
  - `queued` - 排队中
  - `processing` - 处理中
  - `completed` - 已完成
  - `failed` - 失败
</ResponseField>

<ResponseField name="error" type="string">
  错误信息。当任务状态为 `failed` 时返回。
</ResponseField>
