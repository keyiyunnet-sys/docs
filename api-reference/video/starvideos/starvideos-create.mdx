# StarVideos 创建视频任务

创建 `StarVideos` 视频生成任务。该接口支持纯文生、单图生视频，以及首尾帧视频 3 种模式。

## 认证

所有请求都需要在请求头中包含 Bearer token：

```bash
Authorization: Bearer {{key}}
```

## 请求参数

<ParamField body="prompt" type="string" required>
  视频生成提示词。

  示例：`"赛博朋克城市夜景，镜头慢慢推进"`
</ParamField>

<ParamField body="model" type="string" required>
  模型名称，当前固定为 `starvideos_v3`。
</ParamField>

<ParamField body="duration" type="integer">
  视频时长，单位为秒。默认 `5`，允许范围 `3-15`。
</ParamField>

<ParamField body="ratio" type="string">
  输出比例。默认 `16:9`。

  可选值：
  - `16:9` - 横屏
  - `9:16` - 竖屏
</ParamField>

<ParamField body="image_urls" type="array">
  单图输入字段，图生视频时传 `1` 张图片 URL。

  使用规则：
  - 不传 `image_urls`：按文生视频处理
  - 传 `1` 张图：按单图生视频处理

  <Note>`image_urls` 仅用于单图输入；首尾帧请使用 `first_image` 与 `last_image`。</Note>
</ParamField>

<ParamField body="first_image" type="string">
  首帧图片 URL，仅首尾帧视频模式使用。
</ParamField>

<ParamField body="last_image" type="string">
  尾帧图片 URL，仅首尾帧视频模式使用，必须搭配 `first_image`。
</ParamField>

<ParamField body="images" type="array">
  兼容旧字段：参考图 URL 数组。

  使用规则：
  - 不传 `images`：按文生视频处理
  - 传 `1` 张图：按单图生视频处理
  - 传 `2` 张图：按首尾帧视频处理

  <Note>超过 2 张时，仅前 2 张生效。</Note>
</ParamField>

<Info>
**兼容说明：**
- 历史字段 `images` 仍可继续使用
- 同时传新旧字段时，优先按新字段处理
- 同时传新旧字段且值不一致时，接口会返回参数冲突
</Info>

## 响应参数

<ResponseField name="id" type="string">
  视频生成任务的唯一标识符，用于后续查询任务状态。
</ResponseField>

<ResponseField name="object" type="string">
  对象类型，固定为 `video`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建时间戳。
</ResponseField>

<ResponseField name="model" type="string">
  使用的模型名称。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：
  - `queued` - 排队中
  - `processing` - 处理中
  - `completed` - 已完成
  - `failed` - 失败
</ResponseField>

<ResponseField name="error" type="string">
  错误信息。当任务状态为 `failed` 时返回。
</ResponseField>

## 参数约束

<Warning>
**关键约束：**
- `model` 当前仅支持 `starvideos_v3`
- `duration` 必须在 `3-15` 秒之间
- `ratio` 仅支持 `16:9` 或 `9:16`
- `image_urls` 仅支持 `1` 张图片
- `first_image` 与 `last_image` 必须成对传入
- `images` 最多使用前 `2` 张
</Warning>

<Info>
**最佳实践：**
1. 创建任务为异步处理，请保存返回的 `id`。
2. 提示词建议同时包含主体、动作、镜头和风格信息。
3. 首尾帧模式下，建议两张图片在风格和主体上保持连贯。
4. 单图或双图 URL 需要为可访问的公网地址。
5. 已接入历史字段 `images` 的调用方可以继续使用旧字段。
</Info>

<RequestExample>

```bash cURL - 文生视频
curl --request POST \
  --url https://zcbservice.aizfw.cn/kyyReactApiServer/v1/starvideos/videos \
  --header 'Authorization: Bearer {{key}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "赛博朋克城市夜景，镜头慢慢推进",
    "model": "starvideos_v3",
    "duration": 5,
    "ratio": "16:9"
  }'
```

```bash cURL - 单图生视频
curl --request POST \
  --url https://zcbservice.aizfw.cn/kyyReactApiServer/v1/starvideos/videos \
  --header 'Authorization: Bearer {{key}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "女孩在花海中转身微笑，镜头轻微推进",
    "model": "starvideos_v3",
    "duration": 5,
    "ratio": "9:16",
    "image_urls": [
      "https://example.com/girl-flower.jpg"
    ]
  }'
```

```bash cURL - 首尾帧视频
curl --request POST \
  --url https://zcbservice.aizfw.cn/kyyReactApiServer/v1/starvideos/videos \
  --header 'Authorization: Bearer {{key}}' \
  --header 'Content-Type: application/json' \
```
