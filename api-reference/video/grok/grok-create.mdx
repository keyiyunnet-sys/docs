# Grok 创建视频任务

使用 Grok 模型创建视频生成任务，支持文生视频和图生视频。

## 认证

所有请求都需要在请求头中包含 Bearer token：

```bash
Authorization: Bearer {{key}}
```

<ApiBaseUrlZh />

## 模型介绍

支持的模型：

- `grok_video3`：可变时长 `6-30` 秒，支持 `480p` / `720p` 分辨率，按秒计费，默认 `10` 秒 + `16:9` + `720p`
- `grok_video3_pro`：固定 `10` 秒视频，默认按 `16:9` + `720p` 处理
- `grok_video3_max`：支持 `6 / 10 / 12 / 16 / 20 / 30` 秒，支持 `480p` / `720p`，默认 `10` 秒 + `16:9` + `720p`
- `grok_video3_stable`：支持 `6` / `10` 秒，支持 `480p` / `720p`，按次计费 `0.4` 元/次，默认 `10` 秒 + `16:9` + `720p`

## 请求参数

<ParamField body="model" type="string" required>
  模型名称。

  可选值：
  - `grok_video3` - 可变时长 `6-30` 秒（按秒计费）
  - `grok_video3_pro` - 固定 `10` 秒
  - `grok_video3_max` - 支持更多固定时长和更严格的参考图约束
  - `grok_video3_stable` - 支持 `6` / `10` 秒
</ParamField>

<ParamField body="prompt" type="string" required>
  视频生成提示词，描述所需的视频内容。

  示例：`"一只猫在雨中跳舞，电影风格"`
</ParamField>

<ParamField body="duration" type="integer">
  视频时长（秒）。

  规则说明：
  - `grok_video3`：支持 `6-30` 秒，默认 `10` 秒
  - `grok_video3_pro`：固定 `10` 秒，无需设置
  - `grok_video3_max`：仅支持 `6`、`10`、`12`、`16`、`20`、`30` 秒，默认 `10` 秒
  - `grok_video3_stable`：仅支持 `6` 或 `10` 秒，默认 `10` 秒
</ParamField>

<ParamField body="aspect_ratio" type="string">
  输出视频比例。

  规则说明：
  - `grok_video3`：支持 `16:9`、`9:16`、`1:1`、`3:2`、`2:3`，默认 `16:9`
  - `grok_video3_pro`：默认 `16:9`
  - `grok_video3_max`：仅支持 `16:9`、`9:16`、`1:1`，默认 `16:9`
  - `grok_video3_stable`：支持 `16:9`、`9:16`、`3:2`、`2:3`、`1:1`，默认 `16:9`
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率。

  规则说明：
  - `grok_video3`：支持 `480p`、`720p`，默认 `720p`
  - `grok_video3_pro`：默认按 `720p` 处理
  - `grok_video3_max`：支持 `480p`、`720p`，默认 `720p`
  - `grok_video3_stable`：支持 `480p`、`720p`，默认 `720p`
</ParamField>

<ParamField body="image_urls" type="array">
  参考图片 URL 数组（图生视频场景）。

  规则说明：
  - `grok_video3`：最多支持 `7` 张参考图片
  - `grok_video3_pro`：支持参考图片
  - `grok_video3_max`：最多支持 `5` 张参考图片，且必须是公网 URL
  - `grok_video3_stable`：最多支持 `7` 张参考图片，且必须是公网 URL

  示例：`["https://example.com/image1.jpg", "https://example.com/image2.jpg"]`
</ParamField>

## 响应参数

<ResponseField name="id" type="string">
  视频生成任务的唯一标识符，用于后续查询任务状态。
</ResponseField>

<ResponseField name="object" type="string">
  对象类型，固定为 `video`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建时间戳。
</ResponseField>

<ResponseField name="model" type="string">
  创建任务时使用的模型名称。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态。创建成功时固定返回 `queued`。
</ResponseField>

<ResponseField name="error" type="string">
  错误信息。创建成功时通常为 `null`。
</ResponseField>

## 参数使用说明

<Warning>
**关键约束：**
- 不传 `image_urls` 时为文生视频
- 传入 `image_urls` 时为图生视频
- `grok_video3_max` 的比例、时长、分辨率约束最严格，建议优先按枚举值直接传入
- `grok_video3_stable` 仅接受公网可访问的参考图 URL，不支持 base64
</Warning>

## 模型对比

| 特性 | grok_video3 | grok_video3_pro | grok_video3_max | grok_video3_stable |
|------|-------------|-----------------|-----------------|---------------------|
| 时长 | `6-30` 秒，默认 `10` 秒 | 固定 `10` 秒 | `6 / 10 / 12 / 16 / 20 / 30` 秒，默认 `10` 秒 | `6 / 10` 秒，默认 `10` 秒 |
| 比例 | `16:9` / `9:16` / `1:1` / `3:2` / `2:3` | 默认 `16:9` | `16:9` / `9:16` / `1:1`，默认 `16:9` | `16:9` / `9:16` / `3:2` / `2:3` / `1:1`，默认 `16:9` |
| 清晰度 | `480p` / `720p`，默认 `720p` | 默认 `720p` | `480p` / `720p`，默认 `720p` | `480p` / `720p`，默认 `720p` |
| 参考图 | 最多 `7` 张 | 兼容参考图输入 | 最多 `5` 张公网 URL | 最多 `7` 张公网 URL |
| 计费 | 按秒计费 | 按次计费 | 按秒计费 | 按次计费 |

<Info>
**最佳实践：**
1. 创建接口返回任务对象，请保存其中的 `id` 用于后续查询。
2. 提示词尽量描述主体、动作、镜头和风格。
3. 如果使用 `grok_video3_max`，优先使用公网可访问的高质量图片。
4. 如果使用 `grok_video3_stable`，参考图必须是公网可访问的 URL。
5. 图生视频场景下，参考图数量越多，通常排队和生成时间也会更长。
</Info>
