# Grok 查询视频任务

使用任务 ID 查询 Grok 视频生成任务的状态和结果。

## 认证

所有请求都需要在请求头中包含 Bearer token：

```bash
Authorization: Bearer {{key}}
```

<ApiBaseUrlZh />

## 路径参数

<ParamField path="id" type="string" required>
  视频生成任务的唯一标识符，从创建任务接口返回。

  <Note>创建接口直接返回字段 `id`，查询时请将该值作为这里的 `id` 使用。</Note>
</ParamField>

## 响应参数

<ResponseField name="id" type="string">
  视频生成任务的唯一标识符。
</ResponseField>

<ResponseField name="object" type="string">
  对象类型，固定为 `video`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建时间戳。
</ResponseField>

<ResponseField name="model" type="string">
  使用的模型名称，例如 `grok_video3`、`grok_video3_pro` 或 `grok_video3_max`。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：
  - `queued` - 排队中
  - `processing` - 处理中
  - `completed` - 已完成
  - `failed` - 失败
</ResponseField>

<ResponseField name="video_url" type="string">
  生成的视频 URL，当状态为 `completed` 时返回。
</ResponseField>

<ResponseField name="actualDuration" type="number">
  视频实际输出时长（秒），当状态为 `completed` 时返回。
</ResponseField>

<ResponseField name="error" type="string">
  错误信息，当状态为 `failed` 时返回。
</ResponseField>

## 状态流程

<Steps>
  <Step title="queued">
    任务已创建并加入队列，等待处理。
  </Step>
  <Step title="processing">
    任务正在处理中，Grok 模型正在生成视频。
  </Step>
  <Step title="completed">
    任务完成，可通过 `video_url` 获取结果。
  </Step>
</Steps>

## 轮询建议

<Info>
**轮询策略：**
- 建议轮询间隔：30-60 秒
- 不同模型、视频时长和参考图数量会影响完成时间
- `grok_video3_max` 在长时长或多参考图场景下，通常会比基础场景更慢
- 当状态为 `completed` 或 `failed` 时停止轮询
</Info>

## 结果说明

<Warning>
**重要提示：**
- 生成结果通常为临时下载地址，请及时保存
- 参考图较多、时长较长时，处理时间通常更久
- 如提示词或参考图不符合要求，任务可能返回失败状态
</Warning>
