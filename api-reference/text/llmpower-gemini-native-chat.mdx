## 认证

使用 `Authorization` 请求头进行身份认证。

```bash
Authorization: Bearer {{YOUR_API_KEY}}
Content-Type: application/json
```

说明：

- `Authorization`：API 密钥，格式为 `Bearer {{YOUR_API_KEY}}`

## 支持的模型

当前支持以下模型，已按模型家族与版本类型整理：

### Gemini

| 标准 / 稳定版 | 低价版 |
| --- | --- |
| `gemini-2.5-flash-lite` | - |
| `gemini-2.5-pro` | `gemini-2.5-pro-low` |
| `gemini-3-flash-preview` | `gemini-3-flash-preview-low` |
| `gemini-3.1-flash-lite-preview` | - |
| `gemini-3.1-pro-preview` | `gemini-3.1-pro-preview-low` |

### 版本说明

| 后缀 / 类型 | 说明 |
| --- | --- |
| 无后缀 | 标准版 / 稳定版 |
| `-low` | 低价版本 |

### 多模态能力支持

#### 图片分析

全部支持，无需区分。

#### 视频分析

全部支持，无需区分。

## 请求地址

支持以下 Gemini 原生路径：

- `POST /v1/models/{model}:generateContent`
- `POST /v1/models/{model}:streamGenerateContent`

完整地址示例：

```text
http://apillm.globalaiopc.com/gw_llm_power/v1/models/gemini-3.1-pro-preview:generateContent
```

## 请求参数

<ParamField path="contents" type="array" required>
  Gemini 原生消息内容数组。每个元素通常包含 `role` 和 `parts`
</ParamField>

<ParamField path="contents[].role" type="string">
  消息角色，常见值为 `user` 或 `model`
</ParamField>

<ParamField path="contents[].parts" type="array" required>
  消息片段数组。常见为 `text` 对象，也支持 Gemini 原生多模态结构
</ParamField>

<ParamField path="contents[].parts[].text" type="string">
  文本内容
</ParamField>

<ParamField path="generationConfig.temperature" type="number">
  采样温度
</ParamField>

<ParamField path="generationConfig.topP" type="number">
  核采样参数
</ParamField>

<ParamField path="generationConfig.maxOutputTokens" type="integer">
  最大输出 token 数
</ParamField>

<ParamField path="systemInstruction.parts[].text" type="string">
  系统提示词，可选
</ParamField>

## 响应说明

接口返回 Gemini 原生风格响应。

<ResponseField name="candidates[].content.parts[].text" type="string">
  模型生成的文本内容
</ResponseField>

<ResponseField name="candidates[].finishReason" type="string">
  生成结束原因
</ResponseField>

<ResponseField name="usageMetadata.promptTokenCount" type="integer">
  输入 token 数
</ResponseField>

<ResponseField name="usageMetadata.candidatesTokenCount" type="integer">
  输出 token 数
</ResponseField>

<ResponseField name="usageMetadata.totalTokenCount" type="integer">
  总 token 数
</ResponseField>

## 注意事项

<Note>
1. 路径中的 `{model}` 需要替换为实际模型名，例如 `gemini-3.1-pro-preview`
2. 流式场景请使用 `:streamGenerateContent`
3. 请使用 `Authorization` 请求头传递 API 密钥
</Note>
