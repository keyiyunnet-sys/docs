## 认证

使用 `Authorization` 请求头进行身份认证。

```bash
Authorization: Bearer {{YOUR_API_KEY}}
Content-Type: application/json
```

说明：

- `Authorization`：API 密钥，格式为 `Bearer {{YOUR_API_KEY}}`

## 请求参数

<ParamField path="model" type="string" required>
  要使用的模型名称，例如：`claude-opus-4-6`、`gemini-3.1-pro-preview`、`gpt-5.5`
</ParamField>

<ParamField path="max_tokens" type="integer" required>
  本次请求允许生成的最大 token 数
</ParamField>

<ParamField path="messages" type="array" required>
  Claude Messages 协议的消息数组
</ParamField>

<ParamField path="messages[].role" type="string" required>
  消息角色，常见值为 `user`、`assistant`
</ParamField>

<ParamField path="messages[].content" type="string/array" required>
  消息内容。可以是字符串，也可以是 Claude 原生内容块数组
</ParamField>

<ParamField path="system" type="string">
  系统提示词，可选
</ParamField>

<ParamField path="stream" type="boolean">
  是否启用流式响应。开启后返回 Claude 风格流式事件
</ParamField>

<ParamField path="temperature" type="number">
  采样温度
</ParamField>

## 响应说明

接口返回 Claude Messages 风格响应。

<ResponseField name="id" type="string">
  响应唯一标识
</ResponseField>

<ResponseField name="type" type="string">
  响应类型，通常为 `message`
</ResponseField>

<ResponseField name="role" type="string">
  返回消息角色，通常为 `assistant`
</ResponseField>

<ResponseField name="content[].type" type="string">
  内容块类型，常见为 `text`
</ResponseField>

<ResponseField name="content[].text" type="string">
  模型生成的文本内容
</ResponseField>

<ResponseField name="stop_reason" type="string">
  生成结束原因
</ResponseField>

<ResponseField name="usage.input_tokens" type="integer">
  输入 token 数
</ResponseField>

<ResponseField name="usage.output_tokens" type="integer">
  输出 token 数
</ResponseField>

## 注意事项

<Note>
1. Claude 格式请求路径为 `POST /v1/messages`
2. 流式场景请在请求体中传递 `"stream": true`
3. 请使用 `Authorization` 请求头传递 API 密钥
</Note>

<RequestExample>

```bash cURL (纯文本)
curl --request POST \
  --url http://apillm.globalaiopc.com/gw_llm_power/v1/messages \
  --header 'Authorization: Bearer {{YOUR_API_KEY}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "claude-opus-4-6",
    "max_tokens": 1024,
    "system": "你是一个专业写作助手",
    "messages": [
      {
        "role": "user",
        "content": "请帮我写一段产品介绍"
      }
    ]
  }'
```
