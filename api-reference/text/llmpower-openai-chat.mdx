## 认证

使用 `Authorization` 请求头进行身份认证。

请求头要求：

```bash
Authorization: Bearer {{YOUR_API_KEY}}
Content-Type: application/json
```

说明：

- `Authorization`：API 密钥，格式为 `Bearer {{YOUR_API_KEY}}`
- `baseUrl`：`http://apillm.globalaiopc.com/gw_llm_power`

| 后缀 / 类型 | 说明 |
| --- | --- |
| 无后缀 | 满血版 / 官方标准版 |
| `-hc` | AWS 版或优质号池版本 |
| `-fd` | 号池 / 反代版本 |
| `-low` | 低价版本 |

### 多模态能力支持

全部支持，无需区分。

## 请求参数

<ParamField path="model" type="string" required>
  要使用的模型名称，例如：`gpt-5.4`、`gpt-5.5`、`claude-opus-4-7`
</ParamField>

<ParamField path="messages" type="array" required>
  对话消息数组。每个消息对象通常包含 `role` 和 `content` 字段
</ParamField>

<ParamField path="temperature" type="number">
  采样温度，控制输出的随机性。建议范围为 0 到 2
</ParamField>

<ParamField path="top_p" type="number">
  核采样参数。建议与 `temperature` 二选一调整
</ParamField>

<ParamField path="stream" type="boolean">
  是否启用流式返回。设置为 `true` 时，响应将以 SSE 格式返回，并以 `data: [DONE]` 结束
</ParamField>

<ParamField path="max_completion_tokens" type="integer">
  模型最大输出 token 数
</ParamField>

<ParamField path="stop" type="string/array">
  停止生成的序列，可传字符串或数组
</ParamField>

### Messages 数组结构

<ParamField path="role" type="string" required>
  消息角色，可选值：`system`、`user`、`assistant`
</ParamField>

<ParamField path="content" type="string/array" required>
  消息内容。可以是纯文本字符串，也可以是 OpenAI 兼容的多模态数组
</ParamField>

## 响应说明

接口返回 OpenAI 兼容格式响应。

<ResponseField name="id" type="string">
  本次对话请求的唯一标识
</ResponseField>

<ResponseField name="object" type="string">
  返回对象类型，通常为 `chat.completion`
</ResponseField>

<ResponseField name="created" type="integer">
  响应创建时间戳
</ResponseField>

<ResponseField name="model" type="string">
  实际使用的模型名称
</ResponseField>

<ResponseField name="choices[].message.role" type="string">
  模型返回消息角色，通常为 `assistant`
</ResponseField>

<ResponseField name="choices[].message.content" type="string">
  模型生成的文本内容
</ResponseField>

<ResponseField name="usage.prompt_tokens" type="integer">
  输入 token 数
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  输出 token 数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  总 token 数
</ResponseField>

## 注意事项

<Note>
1. 请求地址固定为 `http://apillm.globalaiopc.com/gw_llm_power`
2. 请使用 `Authorization` 请求头传递 API 密钥
3. 流式响应使用 SSE 返回，结束标志为 `data: [DONE]`
</Note>
